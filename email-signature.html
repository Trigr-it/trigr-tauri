How to install this signature

  1. Gmail (web): Settings → See all settings → General tab → scroll to Signature → Create new. Select the preview above, copy (Ctrl+C), paste into the signature editor, save changes.
  2. Outlook (web): Settings cog → Mail → Compose and reply → paste into the signature editor.
  3. Outlook (desktop): File → Options → Mail → Signatures. Paste into the editor. Note: Outlook desktop uses Word's HTML renderer — the gold badge will be a sharp-cornered rectangle there instead of rounded. Tables and colours are preserved.
  4. Apple Mail: Mail → Settings → Signatures. Drag the preview from the browser into the signature pane, or paste.
  5. If links lose their colour after pasting, your client overrode the inline styles. Re-set them manually using #c8860a.
