What we've built.

Seven major releases, 100+ patch versions, every feature visible. Filter by tier to focus on what matters.

Filter
v0 — The Prototype Feb — Mar 2026 Shipped
Visual Keyboard UI Free
Click any key to assign an action. Full keyboard, modifier bar, arrow keys, numpad, and all 7 mouse buttons. No scripting, no config files. The core idea that started Keyfire.
7 Action Types + Macro Sequences Free
Type Text, Send Hotkey (hold/repeat modes), Macro Sequence, Open App/URL/Folder, Focus Window. Chain steps with drag-drop reorder, repeat counters, and Wait for Input.
Text Expansions Free
Trigger word + Space fires replacement text anywhere. Fill-in fields, global variables, image expansions, categories with colour-coding and drag-reorder.
AHK Script Runner Free
Paste any AutoHotkey script body as a macro step or standalone action. Bundles AHK — no installation needed. v1 and v2 syntax.
v0.1 — The Foundation 46 releases · Apr 2026 Shipped
Clipboard Manager Free Pro
History, search, pin, edit, auto-tagging (Text/Link/Email/Colour/Number/Image), source app capture, Ctrl+Shift+V quick-paste overlay, scratchpad. Free: 7-day retention. Pro: 30-day retention, source tagging.
App-Specific Profiles Free Pro
Free: up to 3 global profiles. Pro: unlimited profiles, app auto-switching via foreground watcher. Profile export/import, right-click link/unlink, drag-drop reorder.
Mouse Button Remapping Free
All 7 buttons assignable in app-linked profiles. Hold/release mirroring, modifier passthrough, bare key support, double-press detection.
Onboarding + Infrastructure
5-step onboarding tour, starter template packs, list view toggle, macro speed presets, shared config sync via Dropbox/OneDrive, automatic rolling backups.
v0.2 — Quick Search Overlay 5 releases · Apr 27 — 30 Shipped
Quick Search Overlay Free
Ctrl+Space from anywhere. Instantly search all assignments, expansions (including body text), and search templates. Fire ChatGPT, Perplexity, Google queries with trigger+Space. User categories with colours and drag-reorder.
Analytics Dashboard Free Pro
Period summaries (Today/7/14/30 days), activity chart + heatmap, streak tracking, three-column leaderboards, ROI calculator, expansion efficiency ratio. All local.
UI Overhaul
Keyboard layout rebuilt with arrow keys and nav cluster. Macro panel widened to 450px with inline inputs. Clipboard overlay redesigned. Consistent edit panels across all views.
Smart Case + Sorting
Smart case matching — type "Brb" to get "Be right back", "BRB" for "BE RIGHT BACK". Sortable columns in expansion and assignment lists.
Double-Press Hotkeys Pro
Assign separate actions to single press and double press of the same key. Configurable detection timer (150-500ms). Works for both keyboard and mouse buttons.
Hold Mode + Repeat Mode Free
Hold mode: first press holds, second press releases. Repeat mode: first press starts auto-firing at a configurable interval, second press stops. Works for keyboard and mouse targets.
Starter Templates Free
Three ready-made packs: General/Office, CAD/Engineering, Sales/BD. One-click import with app-specific profile creation for CAD workflows.
v0.3 — Radial Menu 10 releases · May 1 — 5 Shipped
Radial Menu Pro
Hotkey-triggered SVG wheel at cursor position. 8 segments per ring, folder nesting, per-profile configuration, 1500+ Lucide icons, Simple Icons, custom images, drag-drop reorder. Originally planned for v1.2 — shipped 6 months ahead of schedule.
Voice Triggers Experimental
Say a phrase, fire an action. WinRT speech recognition with grammar-constrained matching. 100% offline — audio never leaves your device. Per-action voice phrases, mic test with live level meter.
Image Expansions Free
Paste PNG or JPEG images via trigger word. Scalable (10-100%), clipboard paste with CF_DIB + PNG stream for compatibility across Office, browsers, and design tools.
Dynamic Tokens Free
Date/time tokens with date math ({date:+7d}), clipboard transforms ({clipboard:uppercase}, {clipboard:trim}), cursor placement. Expansions that adapt to context.
Profile Export/Import Free
Right-click any profile to export as .json. Share with colleagues or move between machines. Import with copy/overwrite collision handling.
Config Sync Pro
Point Keyfire at a Dropbox or OneDrive folder. Config syncs across machines automatically with file watching, conflict detection, and self-write suppression.
v0.4 — Hardening & Trust 35 releases · May — Jun 2026 Shipped
Microsoft Code Signing
Microsoft Azure Trusted Signing on every installer. SmartScreen-clean installs out of the box, no more "unknown publisher" warnings.
Offline Beta Keys Pro
Ed25519 offline beta keys, manually issued on email request. 30-day expiry, fully local verification. No accounts, no phone-home.
Anonymous Daily Telemetry Free
Once-daily anonymous usage summary, opt-out in Settings. No IDs, no IPs, no third-party SDKs. Per-day action counts only, no persistent install ID by design.
Clipboard Stability + OCR Free
Re-entrancy guards on paste and copy operations. OCR-from-image clipboard modes (as shown, as paragraphs). Full text emitted on every new clipboard event.
Game-Friendly Hooks Free
LL mouse hook auto-pauses while a fullscreen or borderless app has focus, eliminating input lag in games. WebView2 windows suspend after 5 min idle for a lower RAM footprint when minimised to tray.
Macro Polish: Wait for Input Free
Wait-for-Input macro trigger pauses execution until you press a key. Condensed type selector. App, URL, and Folder merged into a single Open step. Per-type macro labels.
v0.5 — Encryption & Game Compatibility 3 releases · Jun 2026 Shipped
Clipboard Encryption at Rest Free Pro
AES-256-GCM encryption on the clipboard history database, with a DPAPI-wrapped master key tied to your Windows user. Legacy plaintext rows migrated automatically. Search still works, decryption happens in memory.
Scancode Injection for Games Free
Every synthetic keystroke now uses scancode-mode SendInput. DirectInput and Raw Input games (FPS engines, fighting games, BricsCAD) finally see Keyfire's keypresses where VK-only injection was silently invisible.
Hold Trigger Mode Pro
Third trigger mode alongside single press and double press. Fires a separate action when you hold a key past a configurable threshold. Race-condition fixes for overlapping triggers.
Quality of Life Free
Clipboard column toggle. Overlay HiDPI positioning fix at non-default display scaling. Popup height clamp on long lists. Profile-link discoverability tip. Live diagnostics for mouse, keyboard, and outside-click events.
v0.6 — Macro Recorder & Polish Jun 2026 Shipped
Macro Recorder — Phase 1 Free Pro
Hit record, do the thing, play it back. Captures keystrokes, mouse clicks and movement, modifier state, and the timing between every event. Saved as a fully editable macro you can re-bind to any trigger.
Radial Menu Refresh Free
Wedges now read as raised against the desktop with a dedicated idle surface variable. Hover gradient keeps its gold treatment in both themes. Light theme gets a clean white wedge base.
Esc = Global Macro Cancel Free
Press Esc to bail out of any running macro — loops, one-shots, and recorded replays. Chunked sleep polling honours the cancel within 100ms, even on long Wait steps.
Replay Without Suppression Free
Recorded macros replay through the low-level hook so other Trigr features still fire during playback. Trailing modifier keys are trimmed on stop so Ctrl/Shift never stick.

03The story

Rebuilt from the ground up.

Keyfire was originally built on Electron — a 77MB installer, 150-250MB RAM, and noticeable battery drain. We rewrote the entire backend in Rust using Tauri v2, keeping the same React UI. The result: native performance, a fraction of the footprint, and a clear path to Mac support. Every feature migrated and verified on both x64 and ARM64 Windows.
