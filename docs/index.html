06Questions

The questions you're
about to ask.

Built solo, shipped solo, supported solo — happy to answer anything else over email.

Is it really free?
Yes — fully free during Beta and the core feature set stays free at v1.0. Pro and Teams licences ship at v1.0 with extras (advanced analytics, shared snippet libraries, admin management). Everyone testing now gets early access and a thank-you discount at launch.
How is this different from AutoHotkey?
Trigr ships with AutoHotkey built in — both v1 and v2 — so any script you have today still runs. The difference is everything else: visual setup, app profiles, voice commands, text expansions, quick search, clipboard history. AHK becomes one of seven action types, not the only one.
Does it phone home? Where does my data live?
Everything stays on your machine. Config, clipboard history, analytics — all in plain JSON and SQLite files in your %LOCALAPPDATA%. No accounts, no cloud, no telemetry. Voice commands (currently experimental) run locally via the Windows speech engine — no audio is ever transmitted.
Will my IT team allow it?
Trigr ships as a signed ~9MB installer that installs per-user. No admin rights, no system services, no network calls outside the optional update check. It installs to your user folder and uninstalls in one click via Add/Remove Programs. Most enterprise IT departments approve it as a standard productivity tool, since nothing it does requires elevated permissions or touches shared system files.
Will it work in Outlook / Excel / Revit / Slack?
Yes. Trigr works at the OS level using low-level keyboard hooks — the same mechanism every Windows shortcut already uses. If you can type into the app, Trigr works in it. No per-app integration required.
Does it slow my computer down?
No measurable impact. ~30MB of RAM and effectively 0% CPU when idle. The keyboard hook is callback-driven (no polling) and per-key processing is sub-millisecond. You won't notice it's running.
Can my whole team share configs?
Yes — point Trigr at a shared folder (network drive, OneDrive, Dropbox) and everyone on your team gets the same hotkeys, expansions and macros. Live-synced, file-watcher-backed, conflict-managed. Handy for support teams, ops, or anyone with a shared playbook.

Two clicks past the SmartScreen warning

Windows shows a SmartScreen popup the first time you run any new app. It is not an error, just an extra check. Here is how to get past it.

1 Click More info on the blue SmartScreen popup.
2 Click Run anyway to launch the installer.
Trigr is built and signed by Node Group Ltd — you’ll see this name as the publisher in the SmartScreen warning, confirming you have the real installer. The warning clears once Microsoft has seen enough installs from our signed builds.

Trigr uses cookies to understand which channels send us new users. The app itself runs fully offline — your data never leaves your device.
